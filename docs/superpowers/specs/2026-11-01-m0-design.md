# M0 合成辨识闭环

用户已批准无真机闭环、三个独立仓库、Pixi、测试与 GitHub 发布。实现选择：Python 3.12 标准库，单自由度离散质量阻尼系统 v[k+1]=v[k]+dt*(u[k]-c*v[k])/m。相较立即接入仿真器，此模型可独立检验数据合同和失败路径；不构成真实机器人或连续积分器验证。

Core 提供版本化 Dataset(dt, velocity, effort, split, seed)、Parameters(mass,damping)、MockRobot.collect、fit、rollout_rmse、run_demo。数据长度 N+1 / N，有限数值、正 dt、至少 3 个样本。拟合只接收训练数据，不接收真值。求解两列最小二乘，秩不足返回 UNIDENTIFIABLE，非物理解返回 INVALID_MODEL。

Bench 独立生成多个真值系统的最终测试集，计算质量/阻尼相对误差与自由回放 RMSE；使用固定种子和预先声明阈值，覆盖静止激励拒绝。Ecosystem 示例将外部 CSV 转成 Core 合同，禁止重复定义合同，明确仅离线支持。

报告包含 schema_version、种子、数据 SHA256、模型、指标、状态/失败原因；JSON 不允许 NaN。三个仓库各自 pixi run demo/test，Bench 和 Ecosystem 固定 Core Git 提交依赖，单独克隆可运行。真实 SDK、Agent、自动实验、安全执行器、数字孪生均不在 M0。
