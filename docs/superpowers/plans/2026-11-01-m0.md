# M0 Implementation Plan

**Goal:** 三仓库完成合成闭环、独立验收及离线扩展示例。
**Architecture:** Core 维护数据与模型合同，Bench 独立验收，Ecosystem 消费 Core 合同。
**Tech Stack:** Python 3.12、标准库、Pixi、unittest、GitHub Actions。
**Spec:** ../specs/2026-11-01-m0-design.md

## Global Constraints
中文社区文档；无真机；固定种子；独立数据；无凭据；各仓库锁定环境。

## Review Focus
无效数字、长度错配、无激励、非物理解、训练测试泄漏均必须拒绝；错误进程退出码非零。

## Tasks
- [ ] Core：先写参数恢复/失败/重复运行测试，运行确认失败，再实现 roboidf 包、CLI 与 JSON 报告。pixi run test/demo 验收。
- [ ] Bench：固定 Core 提交依赖，独立动力学生成数据，测试正确模型通过/错误模型失败/不可辨识拒绝，输出汇总 JSON。
- [ ] Ecosystem：CSV 离线适配器和元数据，测试列/数值/时间校验，运行 Core 拟合与保留集回放。
- [ ] 同步三个 README、贡献指南、总览与 CI；运行独立克隆验证，审查 diff 后提交推送。
