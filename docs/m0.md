# M0 合同与复现

模型为 `v[k+1] = v[k] + dt*(u[k]-c*v[k])/m`，质量 kg、阻尼 N·s/m、速度 m/s、输入力 N、采样周期 s。初始速度可非零。

`Dataset(dt, velocity, effort, split, seed)` 要求 N 个力、N+1 个速度、N>=3、有限数值、正采样周期，split 为 train/validation/test。只有 train 可传给 fit。数据 SHA256 包括数值和元数据；同一环境、同一配置可重现。

`fit(data)` 返回 `Parameters(mass,damping)`，不访问模拟器真值。它对差分加速度与输入力/速度做两列最小二乘；无独立激励拒绝为 UNIDENTIFIABLE，非物理解拒绝为 INVALID_MODEL。该基线没有测量噪声修正，差分与回归在含噪数据上可能有偏差。

`rollout_rmse(model,data)` 从第一个观测状态自由回放，不在每一步重置到观测值。报告包含种子、训练/验证数据哈希、模型、参数相对误差和 m/s 单位的回放 RMSE。
