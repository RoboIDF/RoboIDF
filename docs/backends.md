# SciPy 标量辨识后端（2026-11-01）

这是 M3 的软件子集：单自由度质量阻尼系统的离线辨识、数值诊断及候选激励选择。不是完整 M3，不包含 MuJoCo、Isaac、机械臂动力学或真机驱动。

运行 `pixi run --locked python -m roboidf.backends` 输出严格 JSON 并保存 `artifacts/backend.json`；成功返回 0，辨识拒绝返回 1。`pixi run --locked test` 包含后端回归。

`fit_bounded(train, validation, FitConfig(...))` 仅接受明确标注的训练集与验证集，不接受 test。SciPy `least_squares` 对 Euler 离散模型的整段自由回放残差拟合 mass、damping；不读生成器或真值。初始参数、物理边界、验证误差阈值、最大条件数与残差求值总次数均由配置声明。预算计入数值差分所需的额外残差调用，不把 SciPy 的 nfev 当作总调用数。整个参数边界必须满足 Euler 稳定条件。

验证集只在拟合结束后用于一次接受/拒绝，不能用于重启优化。会忽略 split/seed 比较实际数据，拒绝完全相同的训练和验证内容。调用者仍必须保障数据来源隔离；这些检查不能检测部分重叠或证明原始数据从未重用。最终测试由独立 Bench 生成、评估，禁止反馈优化或选择。报告包含 SciPy/NumPy/Python 版本、配置、数据 SHA-256、种子、参数、训练/验证误差、优化状态和失败原因。秩与条件数分别检查观测设计矩阵及最终回放 Jacobian；只证明局部数值可辨识性，不构成统计置信区间或真实物理参数认证。

`select_excitation` 使用调用者提供的名义参数，对候选输入的自由回放有限差分敏感度计算 `log(det(J.T @ J))`，按信息量选择。没有真值、验证集或测试集参数；检查峰值力、变化速率（含零输入起止边界）、候选数与样本数预算。该分数未作噪声白化，不能跨采样率、长度或噪声模型解释为公平信息增益；当前 Bench 候选同长同采样率。约束是离线声明，并非真实机器人安全许可。

`simulate_continuous` 逐段调用 `solve_ivp`，保持每段输入常值，与拟合的 Euler 模型区分。解析阶跃解测试核对连续结果，并确认它不同于 Euler 单步结果。Bench 另外实现连续生成器，不用 Core 生成器自证结果。

当前测试覆盖精确恢复、参数合法性、分区拒绝、预算耗尽、零激励拒绝、验证集失配拒绝、候选约束及连续解析解。未完成：多自由度、带约束机械系统、真实数据与噪声统计建模、MuJoCo/Isaac 接入、真机安全与成熟机器人后端全面评估。
