## 待验证主张

| 主张 | 所需证据 |
|---|---|
| 类型化语义合同减少虚假成功 | 相同任务和后端下的语义故障注入对照 |
| 主动实验减少数据或实验成本 | 固定预算、相同激励族的配对比较 |
| 状态恢复降低重复动作及错误复用 | Mock 执行器故障注入和恢复轨迹 |
| 声明等级防止过度物理解释 | 不可辨识任务的误报统计及人工审查 |
| 真机流程可在批准范围执行 | 设备专属合同、独立停止与授权证据；当前不具备 |

## 更新与复现要求

后续先冻结任务数量、预算、阈值、数据切分、对照和统计方法，再采集封存测试结果。实际数据表必须关联代码提交、后端版本、配置、运行记录与合法发布的数据。正文中的“提出”“拟议”和“待验证”不得在缺少证据时改为“实现”“证明”或“达到”。

参考文献已通过一手页面核对；软件文档为动态链接，尚未固定快照，正式投稿前应补充版本锚点和更完整的系统辨识原始文献。本文不是正式投稿稿，也未确定作者、单位、venue 或发布许可证。
